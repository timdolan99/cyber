# 🎓 DBA experiment for a Comptia Cybersecurity+ Socratic tutor app

This is a socratic tutoring app designed to support students taking the Comptia Cybersecurity+ examinations (0710)

I am developing this as an experiment for the DBA in AI that I will being studying for in December 2026

The key features are these:
* FSM and CAG architectural pillars
* Socratic UI designed to help students develop a deeper understanding of the specific literacy required to succeed
* A guided Socratic dialogue through sections of the course the user can determine
* A free-style Socratic mode that enables the user to prompt
* A rewrite feature in which the user has to improve an answer to a question that has used inaccurate or non-technical language
* A PBQ simulation that trains students to use the 3 criteria response and then grades it
* A test simulator that asks 45 questions similar to the exam; it has an optional timer; it grades out of 900
